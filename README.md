# Postbin project

## Overview
The current version of the app allows the user to create an account and create posts as text. The user can also add friends and see friends' posts.

## Tech stack
### Backend
* Java 22
* Spring Boot
* Spring Data JPA
* Junit 5, Mockito
* Testcontainers
* PostgreSQL
* MapStruct
* Liquibase

### Frontend
* Typescript
* React
* CSS

### CI/CD Tools
* GitHub Action
* Docker



## Run application
To launch the application click here [postbin app](https://postbin.onrender.com)
